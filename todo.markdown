## 확인필요

사용자 확인 없이는 진행할 수 없는 항목입니다. **임의로 채우지 마십시오.**

| 항목 | 상태 | 비고 |

## 배포

리포는 **private**이며, **현재 어디에도 배포하지 않고 로컬 미리보기만 사용합니다**(2026-08-20 결정). 원격 배포를 임의로 설정하지 마십시오.

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| GitHub 도메인 소유 확인 (`ragtailor.com`) | 진행 중 | CNAME보다 **먼저** 할 것. GitHub Settings → Pages에서 코드 발급 후 Cloudflare에 TXT `_github-pages-challenge-ragtailor` 추가. 미확인 상태로 CNAME만 두면 서브도메인 탈취 위험 |
| `fin.ragtailor.com` DNS 레코드 사전 생성 | 진행 중 | 소유 확인 후 진행. Cloudflare(`ragtailor.com`)에 CNAME `fin` → `ragtailor.github.io`, **프록시 해제(DNS only)**. 프록시 상태면 Pages 인증서 발급 실패로 Enforce HTTPS 불가. 2026-08-21 조회 시 미생성(NXDOMAIN) |
| 원격 배포 | 보류 | 필요해지면 방식부터 결정. 유료 플랜으로 Pages 사용 / 배포용 public 리포 분리 |
| 프로덕션 도메인 전환 | 보류 | 사업 완료 시점. 절차는 `CLAUDE.md` 전환 체크리스트 참조 |
