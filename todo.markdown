## 배포

리포는 **private**입니다(2026-08-20 변경). GitHub Pages는 무료 플랜에서 private 리포를 배포하지 않으므로, 아래 중 하나를 정해야 데모 배포가 가능합니다.

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 데모 배포 방식 결정 | 대기 | ① 유료 플랜으로 Pages 사용 ② 본문 확정까지 로컬 미리보기만 사용 ③ 배포용 public 리포 분리 |
| 데모 배포 설정 | 보류 | 위 결정 이후. 대상 `fin.ragtaylor.com` |
| `fin.ragtailor.com` DNS 레코드 사전 생성 | 대기 | 전환 시점의 전파 대기를 없애기 위해 미리 생성. 배포 방식과 무관하게 선행 가능 |
| 프로덕션 도메인 전환 | 보류 | 사업 완료 시점. 절차는 `CLAUDE.md` 전환 체크리스트 참조 |
